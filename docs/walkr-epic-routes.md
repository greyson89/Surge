# Walkr 傳說任務流程

整理自使用者提供的截圖 `har-test/epic/傳說任務流程截圖/`（原為簡體中文，已轉成繁體中文）。
遊戲內實際文字可能略有不同，以 `fleets/current` 擷取到的為準（例如截圖「A.攻打 or B.救他」，遊戲內為「攻打他」「救救他」）。

更新日期：2026-11-24

## 閱讀方式

- 每個事件先繳資源（金幣、食物、資源 A/B/C），再繳能量飛行到下一個事件。
- **❓ 選擇題**：全隊投票，過半數或時間到決定路線；之後走 `A.` 或 `B.` 開頭的事件，走完再合併回主線。`A.`／`B.` 是整理截圖的人自己加的分類，遊戲內的事件名稱沒有這個前綴。腳本要投的路線設定在 `scripts/walkr-epic-auto-contribute.js` 的 `VOTING_CHOICES`。
- 選擇題本身也有能量需求（投票決定後飛行到分支的第一個事件）。
- 部分事件的截圖數值與遊戲內的需求不同（例如巨龍王「冰霜國度遇襲」截圖為金幣 720,000，遊戲內需求為 240），繳納以遊戲內 `fleets/current` 為準。
- `？` 表示原圖為虛線（沒有數值），空白表示不需要。有些事件整列沒有資源數值，原圖就是這樣。
- 傳說 id 對應 `GET /epics`（見 `docs/walkr-epic-events.md`）；id 20「護送迷途的星際旅人」來自使用者另外提供的繁體截圖（2026-11-24），格式不同，沒有飛行時數。
